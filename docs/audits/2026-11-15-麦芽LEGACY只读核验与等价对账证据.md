# 麦芽 `LEGACY_READ_ONLY` 只读核验与等价对账证据

更新：2026-11-15，Asia/Shanghai。

## 结论

`LEGACY_READ_ONLY` 是 v1.3 的默认隔离设计，不是故障。`S4_LEGACY_WRITES_ENABLED` 默认值为 `false`，旧 v1 写入路径继续拒绝；v1.3 正式入口保持可读、可用。维护者确认解除条件为设置 `S4_LEGACY_WRITES_ENABLED=true` 并重启，但当前没有解除必要，继续保持只读。

本轮只读等价对账已完成并通过。等价对账不创建旧流程任务，不修改业务数据，结果已由麦芽维护者验收并留存 GitLab 记录 `96974dc8`。

## 代码证据

对应 GitHub 适配提交 `9901c98`（SQLite 单进程部署适配）：

- `config.py`：`legacy_writes_enabled: bool = False`。
- `main.py`：v1 前缀下，除 auth/users 外的非 GET/HEAD/OPTIONS 请求返回 `409 LEGACY_READ_ONLY`。
- `worker.py`：`IMPORT`、`AGREEMENT`、`EXPORT` 旧任务在只读模式下同样拒绝。
- 解除条件：环境变量 `S4_LEGACY_WRITES_ENABLED=true` 并重启，使新配置进入运行进程。

上述代码路径已从本地可读的 Git 对象 `9901c98` 复核。当前项目 checkout 没有配置 GitLab 远端，因此 `96974dc8` 的 GitLab 对象未在本地重新抓取；该提交号和验收内容来自实际维护者提供的运维回执。
