## 指标字典

| 指标 | 分子 / 分母与计算 | 必须记录的边界 |
|---|---|---|
| S3原始通过率 | original_pass / original_checked | 原始失败/递补仍保留，不能用最终N当原分母；checked0记N/A |
| 主线覆盖率 | 有当前有效分配的去重unit数 / N_received | 是分配覆盖，不是核实完成；过期/取消分配不计 |
| 主线提交进度 | 当前revision已完成有效核实封存的unit数 / N_received | VERIFIED/NEEDS_REVISION/RETURNED分别列；草稿、独立阶段、重复轮次不增分子 |
| 主线有效通过率 | 当前最终revision VERIFIED且所需独立复验通过的unit数 / N_received | 缺材料/修订未验/淘汰不删原分母；原接入总体和最终候选各报一列 |
| 最终候选覆盖 | 最终候选与有效核实一一匹配数 / N_final | N_final与N_received不同须有淘汰/递补原件及血缘；不得借变小分母美化完成 |
| 材料阻塞率 | 当前有未决材料工单的去重unit数 / N_received | 每unit可多工单，但分子去重；工单数另计；阻塞时长与有效作业时长分开 |
| 错误/返工率 | 有指定错误类型/返工的去重unit数 / 已实际检查unit数 | 明确检查分母；多标签错误可重叠，不把各类百分比相加；返工次数另报 |
| 修订复验完成率 | 已独立复验的实质修订数 / 需独立复验的实质修订数 | 分别列revision数与受影响unit数，不能互换；0分母记N/A |
| 观测样本覆盖 | n_selected / n_required；有效配对单元n_paired / n_selected | 小集至少8；实际N<8如实短缺；观测2n份作业/4n次封存不是n |
| 原始κ | m个同scope点/专项对象配对向量得po/pe/κ | `m`是统计标签对象数，不是观测n；按dataset/固定pair/round/字典单列，禁止平均异质κ |
| 扩样/低值动作 | 各动作事件数、受影响unit数、关联源批/新批 | 原n/原κ保持，扩样n_add另列；不能用新轮覆盖原低值 |
| 有效作业耗时 | 独立阶段+比对阶段实际active_minutes；p50/p90按同型单元 | 暂停/等待/休息另记；服务器start/end差不是自动有效工时；回忆估时标方法/误差 |
| 吞吐 | 当前有效完成unit数 / 实际有效人时（同型） | 主核实与观测分开；题/组/对/片段不能混算unit/h；技术/会议工时另列 |
| S5交接状态 | 导出/发送/接收/拒收快照数量及各自最终单元数 | 无回执是待对账，不是已接收；幂等重试不新增一份实际交付 |
| 金丝雀/重复/密封抽检 | 各自正确/检测/抽检数量 ÷ 各自冻结总体 | 金丝雀20—30道100%、重复率≤5%、甲方10%—15%分别报，不与内部观测拼分母 |

`N_received`=本次原接入冻结有效unit总体；`N_final`=经过批准淘汰/递补后最终候选集合；每集都保留两者集合hash。2300是13集配额单元合计，可用于配额总账，不能称“2300道题”。QA-D6用片段、SEC-D3用组、SEC-D4用对；其他按适用规范单位填写。跨单位只汇总配额进度/实际人时，不发布混合“每题耗时”。

## 发报前对账

先冻结源导入账/最终候选账/当前有效核实账/观测配对账/实际工时账，再以各自业务键关联。核N_received与逐条PASS，N_final与对应核实/revision集合，n与A/B/person_id/轮次，m与原point_key顺序；核所有分母非零或N/A、null原因和未舍入动作；核实际耗时来源；核本周与月累计去重差异。最后由真实核查人留差异报告和签认，保留原报与更正版本。
